小考系統 ・ 一次性設定

設定精靈

做完這五步，兒子的連結就能用了。全部免費、不用信用卡。
設定好之後，把最後產生的 config.js 貼回 GitHub，所有科目就同時生效。

1

建立 Supabase 專案

免費方案即可，閒置 7 天會暫停，登入後按 Restore 就好
  1. 開 supabase.com/dashboard，用 GitHub 或 Google 帳號登入。
  2. 按 New project：名稱隨意（例如 home-quiz）、資料庫密碼自行設定並記下來。
  3. Region 選 Southeast Asia (Singapore) 或 Northeast Asia (Tokyo)，延遲較低。
  4. 等 1～2 分鐘建立完成。
2

建立資料表

貼一段 SQL，一次就好

左側選 SQL Editor → New query → 把下面整段貼上 → 按 Run。

已經設定過的人：再跑一次就會補上「再考清單」與「資料庫題庫」資料表，舊資料不會被刪除。

載入中…
3

取得兩個值

Project URL 與 anon public key
  1. 左側 Project Settings（齒輪）→ API。
  2. 複製 Project URL，長得像 https://abcdefgh.supabase.co。
  3. 複製 anon public 那把 key，長得像 eyJhbGci… 或 sb_publishable_…。
這兩把是設計給瀏覽器公開使用的，不算機密；真正保護資料的是第 2 步建立的 RLS 規則。
4

建立推播頻道（ntfy）

免註冊，像廣播電台：訂閱同一個頻道就收得到
  1. 下面按「隨機產生」，得到一組只有你們知道的頻道名稱。
  2. 你的手機安裝 ntfy App，按 Subscribe to topic，輸入這組名稱。
  3. 你的電腦也可以開 https://ntfy.sh/你的頻道名稱，按 Subscribe（允許通知）。
  4. 兒子的裝置不用安裝，他交卷時會自動發送。
只用英數字與減號。不要用姓名、電話或生日。
5
