# 國語文期中考｜每日 50 題（10/19 – 11/6）

給四年級孩子的國語文期中考每日練習。共 **19 張**試卷（10/19 ～ 11/6，含週末），
每張 **50 題**：40 題選擇 ＋ 10 題素養題組（2 個題組 × 5 題）。

## 使用方式

1. 直接用瀏覽器打開 `index.html` 即可（建議 Chrome / Edge）。
2. 首頁點選任一張試卷的「開始測驗」。
3. 作答後可看「正解解析」與每個選項的「錯項解析」。
4. 作答紀錄會存在瀏覽器（localStorage），重新打開會保留進度。

> 若瀏覽器擋住本地檔案，可在資料夾內執行 `node _dev/serve.js`，
> 再開 `http://127.0.0.1:8791/`。

## 命題範圍

康軒國語四上 第一～六課：

- 第一課 水陸小高手（含童詩〈溜直排輪〉）
- 第二課 放學後
- 第三課 我的籃球夢
- 第四課 永遠的馬偕
- 第五課 假如給我三天光明
- 第六課 攀登生命的高峰
- 閱讀階梯一 種樹的人

## 課內字詞比例

出題用字**100%** 來自課本內容（課文＋生字＋語詞＋統整活動頁用語）。
經逐字檢核，全部 950 題的每一個漢字都可在課本中找到，無任何課外字。

## 檔案結構

```
國語文期中考/
├── index.html          # 主程式（首頁卡片 ＋ 測驗引擎）
├── papers/
│   ├── day-01.js … day-19.js   # 19 張試卷（每天一張）
├── _dev/              # 開發／出題工具（可忽略）
│   ├── gen.js         # 由題庫產生 19 張試卷
│   ├── verify.js      # 檢核試卷格式
│   ├── checkpool.js   # 檢核題庫格式
│   ├── coverage.js    # 統計題庫課內字詞比例
│   ├── paper_coverage.js  # 統計試卷課內字詞比例
│   ├── vocab.js       # 課內字詞庫（語料來源）
│   ├── corpus.txt     # 課內字詞純文字語料
│   └── pool/          # 題庫（出題原料）
└── README.md
```

## 重新出卷（進階）

若要重新產生試卷：

```
cd _dev
node gen.js        # 產生 papers/day-01.js ～ day-19.js
node verify.js     # 檢核
node coverage.js   # 題庫課內字比例
node paper_coverage.js  # 試卷課內字比例
```

## 說明

- 本題庫為自編練習題，非官方試題。
- 題庫（`_dev/pool/`）為出題原料，會重複利用於不同日期；
  每張試卷的選項順序會重新排列，答案分布維持 A/B/C/D 均衡。
