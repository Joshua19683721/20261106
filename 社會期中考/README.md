# 社會期中考／期末考｜每日 50 題（10/19 – 11/6）

給四年級孩子的社會期中考／期末考每日練習。共 **19 張**試卷（10/19 ～ 11/6，含週末），
每張 **50 題**：40 題選擇 ＋ 10 題素養題組（2 個題組 × 5 題）。

## 使用方式

1. 直接用瀏覽器打開 `index.html` 即可（建議 Chrome / Edge）。
2. 首頁點選任一張試卷的「開始測驗」。
3. 作答後可看「正解解析」與每個選項的「錯項解析」。
4. 作答紀錄會存在瀏覽器（localStorage），重新打開會保留進度。

> 若瀏覽器擋住本地檔案，可在資料夾內執行 `node _dev/serve.js`，
> 再開 `http://127.0.0.1:8793/`。

## 命題範圍

依四年級上學期社會課本（第三冊）目錄整理，共 **4 個單元 ＋ 主題探究、15 個小節**：

| 單元 | 小節 |
| --- | --- |
| 第1單元 家鄉的自然環境 | Ab-Ⅱ-1 家鄉在哪裡、家鄉的地形；Ab-Ⅱ-2 氣候、水資源與生活、小小探究家：何時旅遊比較好 |
| 第2單元 家鄉的傳統住屋與器物 | Bc-Ⅱ-1 傳統住屋與生活、器物與生活、小小探究家：器物大不同 |
| 第3單元 家鄉的傳統信仰與老街 | Bc-Ⅱ-1 信仰與生活；Cb-Ⅱ-1 老街與生活、小小探究家：老街特色 |
| 第4單元 家鄉的作息、節慶與節日 | Cc-Ⅱ-1 生活的作息；Bc-Ⅱ-1 傳統的節慶；Af-Ⅱ-1 現代的節日；Ac-Ⅱ-1 小小探究家：兒童節大不同 |
| 第5單元 主題探究與實作 | Ab-Ⅱ-1 主題探究：介紹家鄉 |

## 出題方式

- 選擇題庫 **90 題**（15 個小節 × 6 題變體）。
  每張試卷的 40 題選擇，**每個小節至少出現 1 題**，另補 25 題由小節輪替，
  同一張試卷內不出現重複題目；不同天以不同變體輪替。
- 素養題庫 **12 組**（每組 1 篇短文 ＋ 5 題，共 60 題），每張取 2 組。
- 選項以決定性亂數重排，正解平均分布在 A / B / C / D。
- 全部 950 題中，選擇題 90 題皆為不同題目（同一天不重複）。

## 檔案結構

```
社會期中考/
├── index.html          # 主程式（首頁卡片 ＋ 測驗引擎）
├── papers/
│   └── day-01.js … day-19.js   # 19 張試卷（每天一張）
├── _dev/              # 開發／出題工具
│   ├── units.js       # 15 個小節清單（出卷依據）
│   ├── gen.js         # 由題庫產生 19 張試卷
│   ├── verify.js      # 檢核試卷格式
│   ├── serve.js       # 本機預覽用靜態伺服器
│   └── pool/
│       ├── sel-a.js … sel-d.js  # 選擇題庫（90 題）
│       └── pas-a.js、pas-b.js   # 素養題組（12 組）
└── README.md
```

重新產生試卷：

```bash
node _dev/gen.js      # 重新出卷（會覆寫 papers/day-*.js）
node _dev/verify.js   # 檢核試卷格式與分布
```
