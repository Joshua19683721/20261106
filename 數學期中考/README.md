# 數學期中考／期末考｜每日 50 題（10/19 – 11/6）

給四年級孩子的數學期中考／期末考每日練習。共 **19 張**試卷（10/19 ～ 11/6，含週末），
每張 **50 題**：40 題選擇 ＋ 10 題素養題組（2 個題組 × 5 題）。

## 使用方式

1. 直接用瀏覽器打開 `index.html` 即可（建議 Chrome / Edge）。
2. 首頁點選任一張試卷的「開始測驗」，或從科目總覽的日期直接進入。
3. 作答後可看「正解解析」與每個選項的「錯項解析」。
4. 作答紀錄、錯題本與作答模式會存在瀏覽器（localStorage）。

## 出題方式

- 每張試卷 **39 題小節核心題**：39 個小節每個至少 1 題，同一張試卷不重複。
- 每張另有 **1 題跨小節統整題** 與 **2 個素養題組 × 5 題**。
- 選擇題庫 **199 題**，每個小節 4～8 個變體；素養題庫 **20 組**（共 100 題）；統整題 **19 題**。
- 選項以決定性亂數重排，正解平均分布在 A / B / C / D（每卷 13 / 13 / 12 / 12），且不連續三題同答案。
- 19 張試卷合計涵蓋 **39 / 39 個小節**；每張試卷都是完整範圍複習。
