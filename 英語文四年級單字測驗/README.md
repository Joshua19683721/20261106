# 英語文四年級單字測驗

給四年級兒子練單字的小考題庫，掛在 [`小考/`](../小考/) 裡，和其他六科共用同一套作答、計時、交卷通知與檢討流程。

- 來源：《英語單字口袋書（1–6級）》**第 4 級（＝四年級）**，共 **133 個單字**
- 依 **20 個生活場景**分卷（基礎文法、校園學習、飲食餐桌、時間日期…）
- 題庫 **375 題**（每個單字最多 3 種題型）

## 三種題型

| 題型 | 題目長相 | 選項 |
|---|---|---|
| 英 → 中 | `apple /ˈæpəl/` 的中文是什麼？ | 4 個中文意思 |
| 中 → 英 | 「蘋果」的英文是哪一個？ | 4 個英文單字（附音標） |
| 例句填空 | I eat an ______ every day.（中文：我每天吃一顆蘋果） | 4 個英文單字 |

- 干擾項優先用**同一個生活場景**的字，四個選項的中文意思不重複。
- 同一個中文對到兩個單字時（例如 do／does 都是「助動詞」）不出「中→英」，避免一題有兩個正確答案。
- 例句裡真的出現該單字才出填空題，沒有出現的就只出前兩種。
- 每題的詳解都包含：單字、音標、中文意思、課本搭配詞、完整例句與翻譯。

## 怎麼用

兒子一樣從 [`小考/`](../小考/) 進去，往下會看到「英語文四年級單字測驗」，選 20／30／40 題就開始。
作答、計時、交卷推播、爸爸的錯題詳解與「已檢討」標記，全部沿用同一套系統。

## 檔案

```
英語文四年級單字測驗/
  papers/bank.js            題庫（window.EXAM.papers，小考直接讀）
  source/level4.json        第 4 級原始資料（133 個單字）
  tools/extract-level4.js   從口袋書 banks.js 抽出第 4 級
  tools/build.js            產生 papers/bank.js
```

## 重新產生題庫

```bat
node tools/extract-level4.js "C:\path\to\mkes1-6-allgrade\data\banks.js"
node tools/build.js
```

`build.js` 用固定亂數安排選項與正解位置，同樣的來源每次都會產生同樣的題目。
產生完會自動檢查：每題 4 個選項、選項不重複、正解位置正確、詳解存在、題目 ID 不重複；有問題會直接失敗。

## 注意

- 資料夾名稱與 `papers/bank.js` 的位置不要改，小考是靠 `小考/core.js` 的 `SUBJECTS` 指過來。
- 題目 ID 由「題幹＋選項＋正解」算出；改題目文字等於換一題，之前標記「已檢討」的舊題不會再抽到，但新題會被當成新題。
