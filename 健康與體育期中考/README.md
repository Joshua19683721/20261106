# 健康與體育期中考／期末考｜每日 50 題（10/19 – 11/6）

給四年級孩子的健康與體育每日練習。共 **19 張**試卷（10/19 ～ 11/6，含週末），
每張 **50 題**：40 題選擇 ＋ 10 題素養題組（2 個題組 × 5 題）。

## 使用方式

1. 直接用瀏覽器打開 `index.html` 即可（建議 Chrome / Edge）。
2. 首頁點選任一張試卷的「開始測驗」。
3. 作答後可看「正解解析」與每個選項的「錯項解析」。
4. 作答紀錄會存在瀏覽器（localStorage），重新打開會保留進度。

> 若瀏覽器擋住本地檔案，可在資料夾內執行 `node _dev/serve.js`，
> 再開 `http://127.0.0.1:8795/`。

## 出題方式

- 選擇題庫 **85 題**（17 個小節 × 5 題變體）。
  每張試卷的 40 題選擇，**每個小節至少出現 1 題**，另補 23 題由小節輪替，
  同一張試卷內不出現重複題目；不同天以不同變體輪替。
- 素養題庫 **17 組**（每組 1 篇短文 ＋ 5 題，共 85 題），每張取 2 組，17 組全部用到。
- 選項以決定性亂數重排，正解平均分布在 A / B / C / D（每卷 13/13/12/12）。

## 檔案結構

```
健康與體育期中考/
├── index.html          # 主程式（首頁卡片 ＋ 測驗引擎 ＋ 命題範圍說明）
├── papers/
│   └── day-01.js … day-19.js   # 19 張試卷（每天一張）
├── _dev/              # 開發／出題工具
│   ├── units.js       # 17 個小節清單（單元、課本頁碼、對應學習重點）
│   ├── gen.js         # 由題庫產生 19 張試卷
│   ├── verify.js      # 檢核試卷格式與分布
│   ├── serve.js       # 本機預覽用靜態伺服器
│   └── pool/
│       ├── sel-a.js … sel-d.js  # 選擇題庫（85 題）
│       └── pas-a.js、pas-b.js   # 素養題組（17 組）
└── README.md
```

重新產生試卷：

```bash
node _dev/gen.js      # 重新出卷（會覆寫 papers/day-*.js）
node _dev/verify.js   # 檢核試卷格式與分布
```
